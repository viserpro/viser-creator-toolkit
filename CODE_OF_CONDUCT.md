# Code of Conduct

VISER aims to be a welcoming, practical project for creators and developers.

Expected behavior:
- Be respectful and constructive.
- Critique ideas and code, not people.
- Share context and reproducible steps.
- Respect different skill levels and backgrounds.

Unacceptable behavior includes harassment, discrimination, threats, doxxing, and deliberate disruption.

Maintainers may remove content or restrict participation for behavior that violates this policy. Report concerns privately through the contact method listed in the repository's GitHub profile once published.
