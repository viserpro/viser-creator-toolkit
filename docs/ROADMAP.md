# Roadmap

## 0.1.0 - Public starter

- Reusable 9:16 transparent overlay composition.
- Editable title, kicker, subtitle, and accent color.
- Reproducible local preview and render commands.
- Licensing and contribution guidance.

## 0.2.0 - Script input

- Documented JSON scene schema.
- Input validation and actionable errors.
- Synthetic example project and tests.

## 0.3.0 - Creator workflow

- Asset manifest and media preflight.
- Reusable scene and subtitle templates.
- Safe output naming and overwrite protection.

## 0.4.0 - Render reliability

- Preview presets.
- Render metadata report.
- Alpha-channel verification guidance.
- Cross-platform setup notes.

## 1.0.0 - Stable toolkit

- Backwards-compatible input schema.
- CI checks and release process.
- User-tested documentation.
- Contributor onboarding.

Milestones depend on actual user feedback and available maintainer time. No feature or release date is guaranteed.
