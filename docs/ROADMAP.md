# Roadmap

## 0.1.0 - Public starter
- Reusable 9:16 transparent overlay composition.
- Editable title, kicker, subtitle, and accent color.
- Reproducible local preview and render commands.
- Licensing and contribution guidance.

## 0.2.0 - Creator workflow foundation
- Typed creator guidebook with validation.
- One-line-per-scene script compiler and versioned scene output.
- Subtitle wrapping and approximate word cues.
- Asset manifest preflight and audio mix planning.

## 0.2.1 - Creator Workspace
- Local-first browser UI for script and guidebook input.
- Scene compilation, storyboard review, and scene preview.
- JSON project and SRT subtitle export.
- Responsive desktop and mobile layouts.

## 0.3.0 - Media Intelligence and timeline foundation
- FFprobe-backed inventory for video, audio, and image files.
- File metadata, probe failures, and optional SHA-256 duplicate detection.
- Importable media inventory JSON.
- Typed multi-track timeline and sequential video rough cut.
- Non-destructive trim, split, move, add, remove, and timeline JSON export.

## 0.4.0 - Playback and review
- Real source-footage preview and seek/scrub.
- Thumbnail extraction and audio waveform summaries.
- Drag-and-drop timeline placement, snapping, and zoom.
- Undo/redo command history and ripple editing.
- Proxy generation and performance controls for 4K footage.

## 0.5.0 - Media intelligence plus
- Voiceover duration and silence analysis.
- Subtitle alignment against actual audio.
- Portrait crop recommendations and face-aware reframing.
- Timeline-to-Remotion render adapter and render validation.

## 0.6.0 - CapCut bridge
- Read-only CapCut draft inspection and backup workflow.
- Exportable overlay package and timeline placement manifest.
- Optional, user-confirmed timeline insertion where supported.
- No direct draft mutation without backup and explicit confirmation.

## 1.0.0 - Stable toolkit
- Backwards-compatible scene and timeline schemas.
- CI checks, release process, and migration guide.
- User-tested documentation and recovery procedures.

Milestones depend on actual user feedback and available maintainer time. No feature or release date is guaranteed.
